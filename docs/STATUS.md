# Текущее состояние (для новой сессии Claude Code)

Обновлено 12.11.2026. Начинайте сессию с чтения этого файла. Когда пункт сделан, обновите файл в том же PR.

## Как работать с владельцем проекта

- **По одному шагу за раз.** Один вопрос или одно действие в сообщении, следующий шаг — после ответа.
- **Доказывать, что работает,** а не только «сделать»: проверка на локальном Supabase, затем на живом сайте, с выводом команд.
- Интерфейсы Cloudflare, Supabase и DeepL меняются. Если инструкция не совпадает с экраном, попросите снимок экрана и работайте по нему.
- Секреты (ключи, токены, пароли) никогда не присылаются в чат и не видны на снимках. Ключи для API вводятся только в форме секретов окружения.
- Репозиторий **публичный**: никаких личных данных и секретов в коммитах. Папка `scripts/data/` в git не добавляется.

## Как устроено

| Что | Где | Подробности |
|---|---|---|
| Сайт | Cloudflare Workers Free, `https://a11y-shelter-system.priyut-md.workers.dev` | `ops/cloudflare/README.md` |
| Выкладка | Cloudflare сам собирает и выкладывает **только** ветку `main` (сборки веток выключены) | там же |
| База, вход, фото | Supabase Free, проект `czbuyirmoixortuhlekv` | `supabase/` |
| Переводы ro/en | DeepL API Free: сразу после сохранения в панели и ночью в 02:00 UTC | `lib/translateStale.ts` |
| Резервные копии | приватный репозиторий `a11y-shelter-backups`: каждую ночь, учебное восстановление по воскресеньям | `ops/backup/README.md` |
| Мониторинг | UptimeRobot на `/api/health`, письма на почту | |
| Действия координатора | скрипты `scripts/*.ts`, запуск `node --env-file=.env.coordinator scripts/<скрипт>.ts …`, без `--apply` — пробный запуск | комментарий в начале каждого скрипта |

У сессии Claude Code есть токен Cloudflare **только для чтения** (секрет окружения для `api.cloudflare.com`): через него проверяются настройки Worker, сборки и метрики.

## Хостинг и нагрузка (замеры 12–13.11.2026)

Ожидания владельца: 500 животных, ~100 нужд и проектов, ~100 правок в день, ~10 000 посетителей в день.

- Логи Cloudflare за 12.11 (916 запросов): фоновые RSC-запросы Next (подгрузка ссылок) — 54% запросов, медиана 17–21 мс; открытие страницы целиком — 72–310 мс; `/api/health` от UptimeRobot — 130 мс; боты на несуществующие адреса — ~300 мс. Дорогие простые ответы указывают на холодный запуск кода (5,6 МБ).
- Локальный визит: каталог даёт 8 запросов к Worker и ~1,8 МБ фото (24 × ~80 КБ карточек 800 px).
- Оценка на 10 000 посетителей в день: Workers Paid ~$9 в месяц (без процентов, только сверх 10 млн запросов и 30 млн мс). Узкое место — трафик фото из Supabase (~1 ТБ в месяц при 5 ГБ бесплатно). План: после домена перенести фото в Cloudflare R2. DeepL (500 000 знаков в месяц) при таком числе правок не замерен.
- План оптимизации на Next, ничего не сделано: 1) `/api/health` ответом в `cloudflare/worker.js` без Next; 2) `prefetch={false}` на ссылках; 3) быстрый 404 для чужих адресов в `worker.js`; 4) кэш публичных страниц; 5) копия фото для карточки 400–480 px; 6) Workers Paid.
- Опыт с Astro: `experiments/astro-catalog` (каталог, результаты в README). Совпадает пиксель в пиксель и по дереву доступности. Процессор ~13 мс вместо 42–55 на прогретом сайте, 40–60 мс вместо 480–540 на первом открытии, HTML 76 КБ вместо 194. Даже Astro не укладывается в 10 мс надёжно. Владелец рассматривает переезд на Astro; решение не принято.
- Сеть среды Claude Code: разрешены `ghcr.io`, `pkg-containers.githubusercontent.com` (локальный Supabase), `fonts.googleapis.com`, `fonts.gstatic.com` (сборка) и адрес живого сайта.

## Локальная проверка (для Claude Code)

- Supabase: `npx -y supabase@2.122.0 start` (при необходимости сначала запустить `dockerd`). Для тестов панели волонтёра временно включить TOTP в `supabase/config.toml` и потом вернуть.
- Next: после проверки останавливать процесс `next-server`, иначе старая версия продолжит отвечать.
- Playwright: `executablePath: "/opt/pw-browsers/chromium"`, для живого сайта — `proxy: { server: process.env.HTTPS_PROXY }`.
- `next dev` переписывает блок в `AGENTS.md`: это изменение можно коммитить.
- Для изменений `package-lock.json` использовать `npx -y npm@11` (npm 10 теряет поля `libc`).
