# Скрипты координатора

Запуск с компьютера координатора, ключ service role — в `.env.coordinator` (`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, для приглашений ещё `SITE_URL`):

```bash
node --env-file=.env.coordinator scripts/<скрипт>.ts …
```

**Каждый скрипт без `--apply` только показывает, что сделает, и ничего не меняет.** На сайте один приют, поэтому адрес приюта (slug) больше не указывается.

| Скрипт | Что делает |
|---|---|
| `create-shelter.ts "Название" ["Город"]` | заводит строку приюта, если её ещё нет (приют скрыт, пока `is_published = false`) |
| `invite-volunteer.ts почта` | создаёт вход, добавляет человека в волонтёры и печатает одноразовую ссылку-приглашение |
| `reset-password.ts почта` | печатает одноразовую ссылку, по которой волонтёр задаёт новый пароль (если он забыл старый). Если у волонтёра включён двухфакторный вход, на странице нужно ввести и код из приложения; если потерян и телефон, сначала `reset-2fa.ts` |
| `reset-2fa.ts почта` | удаляет второй фактор волонтёра, если он потерял телефон; человек сразу настраивает его заново |
| `create-project.ts --title "…" --description "…" [--help things,money]` | новый проект без фото (фото добавит волонтёр в панели). В `--description` `\n` — новая строка, строки с `- ` — список |
| `edit-project.ts "текущее название" […]` | правки проекта: `--title`, `--description`, `--photo-alt`, `--progress "5/20 будок"` / `--no-progress`, `--to-top` (первым среди незакреплённых), `--pin` / `--unpin` (постоянная программа: только координатор), `--fix-translation ro\|en "было" "стало"` (исправить фразу в автоматическом переводе; нельзя вместе с правкой текста) |
| `load-needs.ts файл.jsonl` | загружает список нужд (строки JSON: `name`, `category`, `unit`, `quantity`, `urgent`, `note`); существующие по названию обновляет |
| `load-gallery.ts папка` | галерея «О приюте»: из `папка/alts.jsonl` (`file`, `alt`, `alt_en`, `alt_ro`) и снимков делает файлы в `public/shelters/live-life/gallery` и строки `gallery_photos`; лишние удаляет |
| `set-shelter-brand.ts значок.png` | логотип и значки сайта (`brand/<uuid>/…`), старые файлы удаляет |
| `upload-shelter-photo.ts путь "описание"` | фото приюта и превью для ссылок |
| `add-card-copies.ts` | досоздаёт карточки 800 px к фото животных, где их нет |
| `add-preview-copies.ts` | досоздаёт превью для ссылок 1200×630 к фото приюта и животных, где их нет |

Убраны вместе с поддержкой нескольких приютов: `move-projects.ts`, `move-volunteer.ts`, `delete-shelter.ts`.

`sharp` разрешён только здесь, в `scripts/`: эти скрипты работают на компьютере, а не на Cloudflare.

## Тестовые данные для локальной проверки

`seed-local.ts` заполняет **пустую локальную** базу (Supabase в Docker) тестовыми данными: приют «Живи», галерея, 12 собак с фото (из галереи), 10 нужд, 3 проекта и тестовый волонтёр `volunteer@example.org` с паролем `local-test-password`. Скрипт отказывается работать, если `SUPABASE_URL` указывает не на `127.0.0.1` или `localhost`, и если приют в базе уже есть.

```bash
node --env-file=.dev.vars scripts/seed-local.ts
```
